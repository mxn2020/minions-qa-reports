# @minions-qa-reports/cli

CLI for Minions Qa-reports — Aggregated test reports, health dashboards, trend analysis, and regression alerts

## Installation

```bash
npm install -g @minions-qa-reports/cli
```

## Usage

```bash
qa-reports --help
```
